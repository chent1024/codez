## Why

手动归档 CodeZ 托管工作树中的会话后，工作树仍占用磁盘，用户必须再到设置页查找并删除。现有删除只核验工作区文件状态，不能证明提交已推送，可能丢失仅存在于本机的提交。

## What Changes

- 手动归档会话后，自动尝试清理其 CodeZ 托管工作树；普通本地、远程和非托管工作区只执行原有归档。
- 清理前由服务重新核验托管归属、所有关联会话已归档且终止、无本地文件、未锁定，以及当前提交与远端上游分支一致。任何条件不满足或远端不可验证时保留工作树，归档仍成功。
- 设置页的手动移除复用相同的 Git 安全门槛，不能绕开“提交已推送”。旧任务自动归档不触发工作树清理。

## Capabilities

### Modified Capabilities

- `managed-worktree-settings`: 增加手动归档后的有条件自动清理，并加强托管工作树移除的远端提交校验。

## Impact

涉及任务归档服务适配器、任务索引查询、Git 托管工作树删除、服务装配，以及对应的服务级测试。沿用现有任务归档接口和 Git 服务接口，不新增持久状态、后台清理器或 UI 开关。

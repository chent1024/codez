## Design

UI 草稿拥有工作位置和起点分支选择，Git 服务拥有 worktree 创建和 Git 核验，V4 命令继续拥有会话与首条输入接纳。工作树以独立本地 `workspacePath` 进入现有工作区服务和会话索引。选择动作不产生 Git 或会话副作用。

提交顺序：冻结草稿输入与配置 → 单飞创建 worktree → 核验仓库与起点 SHA → 在目标工作区发送一次 `createSession(firstInput)` → accepted 后打开该工作区及会话。创建失败保持原草稿；发送结果未知时保留命令 ID 和工作树以便恢复，不能删除后重试。

本变更仅提供托管目录的创建及会话打开，不提供生命周期清理。新目录使用 CodeZ 数据根目录；不复制源目录未提交或忽略文件，不获取上游更新。没有恢复快照前不得自动删除工作树。远程工作区、手机远控及非 Git 目录继续使用原有路径。

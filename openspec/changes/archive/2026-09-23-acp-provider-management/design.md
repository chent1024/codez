## Design

Host 的 `agent-servers.json` 是自定义 ACP 配置的唯一所有者；UI 只持有当前表单草稿。保留 `saveAgentServer` 更新同一 ID 的路径，新增定向删除命令。两者均校验完整注册表并原子替换文件，失败不发布新列表。

列表状态区分内置与自定义条目，并为自定义条目返回保存所需的原始参数。稳定 ID 不可编辑；命令/参数变更后由现有指纹机制隔离旧模型缓存并拒绝用新进程恢复旧会话。删除只移除注册表项；历史会话及其绑定不变。UI 通过既有服务接口刷新导航和模型选择器。

添加页继续使用现有 API / ACP 选择卡片；选择 ACP 后直接进入自定义配置表单，返回到供应商类型页。ACP 表单采用同页的返回按钮、标题层级、紧凑字段和操作区。已配置条目的更多菜单提供编辑和删除，删除复用现有确认对话框。
